# Road to CELE

Before authoring course descriptions, topic rundowns, future skills or practice activities, read [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md).

Lecture future-skills entries must identify the future subject where each topic will be used and recalled. Once the owner supplies the CIVINCO files, backtrack previous nodes and add “This will also come back in CIVINCO, beware!” only for topics supported by those files. Keep topic rundowns compact. Laboratory resume skills must be tied to verified technical/tool practice and evidence.

Node brightness has three levels: faint and reflective before activation, brighter when active, brightest when academically completed. Light the star itself and nearby constellation segments; do not add broad circular glow effects.

Lectures have Grade calculator at tab IV and Mastery quiz at V. Labs have four tabs ending at Grade calculator, with no mastery quiz. Populate grading schemes only from supplied syllabi; verify weights, passing thresholds, rounding and additional passing conditions. See GRADING_SETUP.md. Batch ID 119–128 is self-reported account profile metadata and does not change academic standing or the ID122 curriculum rules.

Use the site's uploaded Hanyi WenHei font throughout the course panel, matching the rest of the UI; justify its paragraphs. Scroll the title and metadata away while keeping the course code and tabs pinned. Show descriptions before activation; tabs II–V unlock only when that course's academic record is ACTIVE or COMPLETED. Omit source citations from the student panel while retaining provenance internally.

Keep the entire course panel visually distinct and readable with constellation-colored headings, warm topic labels and prose, and soft green skill accents on black. Grade summaries use compact numeric cards and written status labels alongside color; keep secondary options expandable.

The verified owner account can switch Student view / Admin view. Admin experiments use a separate device workspace with unrestricted course access and cosmetic frames. Reset is available only in Admin view and never clears student progress. Roles come from server-verified Supabase identity; editable profile metadata and batch IDs do not grant permissions. See ADMIN_SETUP.md.

Quiz calculator rows use the equally weighted average of each earned/perfect percentage. Accept actual awarded bonus scores above the perfect score. Final Exam has one earned/perfect pair; other requirements take a computed average out of 100. Preserve syllabus weights. Unsaved calculator inputs and planning targets never change completion.

Use verified course-specific grade tables for 1.0–4.0 targets. Display incomplete results as weighted points earned toward the final grade, not a renormalized average. A complete, explicitly confirmed score set is the self-reported grade for that subject and journey term. Keep failed attempts, retakes and corrections in history; use separate drafts per course, term and Student/Admin view. Failed grades satisfy activation-based soft requirements, but hard requirements need a passing attempt from an earlier term. Passing conditions can override the numeric grade. A retake uses a later term and fresh scores. Personal map plans retain failed nodes and shift unstarted hard descendants; preserve existing academic records and label shifted terms as plans, not verified course offerings.

Account profile photos are separate from companion avatars and frames. Re-encode uploaded images to a centered 256px JPEG preview capped at 48 KiB of data URL text. Save only after the user applies the preview, in that account's private progress JSON, never Auth metadata/JWTs. Cancel unsaved previews on close or account changes, reject stale image work, and preserve academic records on photo changes. No extra storage bucket or secret is required.

The Non-major checklist is a separate, unordered list with self-reported Year Taken, Term and Taken status. It does not change technical academic records or prerequisites. Use the named GE/LC rows in the supplied ID122 checklist; IDs119–122 use GEFTWEL/GEDANCE/GESPORTS/GETEAMS, while IDs123–128 use the newer PE sequence. Preserve hidden older PE records if batch metadata changes. Keep elective and generic PE slots editable; do not invent specific course offerings. See NON_MAJOR_CHECKLIST.md for provenance and persistence rules.
