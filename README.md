# Road to CELE

A Civil Engineering skill-tree skeleton with a static interface and an optional Cloudflare Pages recovery function with guest saving and optional Supabase accounts with a near-black galaxy UI. Courses appear as constellation stars connected by prerequisite links. One curriculum graph contains shared technical courses and all five specialization branches. Quizzes and course descriptions are intentionally deferred.

Run `npm ci`, `npm test`, `npm run build`, then `npm start`. On Windows PowerShell use `npm.cmd` if execution policy blocks `npm.ps1`. Open http://localhost:4173.

## Architecture

- `src/curriculum.mjs`: shared course identities, ID122 term placement and H/S/C prerequisites, specialization metadata, configurable required mastery scope, and common CELE review groupings.
- `src/progression.mjs`: immutable progression transitions. Preview is read-only; specialist progression requires confirmed self-reported acceptance; a separate confirmed transfer transition retains all records. Academic and mastery completion are separate. CIVINCO requires the active technical path, configured mastery, then a common assessment pass.
- `src/storage.mjs`: versioned local persistence and record hydration. Export a JSON backup from the journal. University acceptance remains self-reported. Google sign-in identifies app accounts only.
- `src/app.js`: independent map state for browsing years, branches, pan and zoom. Actual academic year is self-reported separately in the journal. Unselected branches and explicit Explore All mode disable ordinary progression actions.
- `src/sky-layout.mjs`: real constellation outline projections, course star placement, and canvas dimensions. The shared sky contains Years I–IV together; year controls animate travel through the same map. One specialization constellation can be revealed alongside the shared map at a time. Its prerequisite paths connect to the original shared nodes, without duplicating them. Year, term, and constellation labels sit immediately above the corresponding course clusters, with compact spacing between years. The default zoom keeps stars large, while Fit map shows the full overview. Reduced motion disables navigation animation.
- `src/course-panel.mjs` and `src/course-panel.css`: modal course chapters with Roman numeral tabs for description, topic rundown, future skills and mastery quiz. Content stays as explicit placeholders pending course files. The course constellation, metadata, prerequisites and academic action remain available across tabs. Escape closes the modal; arrow keys navigate tabs.
- `src/map-camera.mjs`: bounds pan and zoom to visible course content, adjusts horizontal limits to the populated part of the sky, and centers an overview that fits within the viewport. Boundary gestures respond immediately when reversed.
- `src/map-pan.mjs`: pointer capture, drag threshold, native selection/drag suppression, and prevention of course activation after a pan gesture.
- `src/connections.mjs`: selecting a prerequisite line traces its upstream prerequisites and downstream dependents on the current map. Unrelated sibling paths stay dimmed. The path panel opens course details without altering progression; line dragging remains a pan gesture. Course details also list downstream hard/soft prerequisites and symmetric co-requisite partners across the common dataset.
- `src/dialog-dismiss.mjs`: dismisses course details only when a primary pointer press and click both land outside the dialog.
- `src/completion.mjs`: cosmetic completion moments derived from academic records, including newly available courses and completed terms. No extra progress currency, mastery, or gate credit is granted. Animations respect reduced motion.
- `src/refinements.css`: final near-black surfaces, a dimmer galaxy, neutral course chapters, and a prominent Reset progress control beside Explore All Specializations. Constellation colors remain on their nodes and outlines.
- `src/scene-camera.mjs`, `src/sky-layout.mjs` and `src/depth.css`: perspective projection of a constellation plane viewed from a 30-degree elevation, with larger raised stars, visible elliptical bases, and base-aligned constellation/prerequisite lines. Larger constellation footprints and collision-aware anchor selection separate dense clusters. Course codes stay beneath the bases in translucent containers; titles appear on hover or keyboard focus. Galaxy and foreground layers use restrained parallax. Reduced motion disables parallax and hover movement. Catalog detail charts keep their original projection and course anchor identity.
- `tests/ui.test.mjs` and `tests/map-pan.test.mjs`: website interactions, read-only preview and chapter navigation, unified year navigation, and pointer gesture regressions.
- `tests/progression.test.mjs`: required V3 regression cases plus dependency enforcement, storage round trips and mastery/gate separation.

- `src/account-progress.mjs`: account-scoped caches, explicit guest import, revision-checked cloud persistence, offline retry and conflict resolution.
- `src/account-browser.mjs`: Google PKCE sign-in, honest save status and sign-out to guest mode.
- `supabase/migrations/202610110001_student_progress.sql`: private progress rows, row-level security, ownership checks and optimistic save revisions.
- `tests/account-progress.test.mjs`, `tests/account-browser.test.mjs` and `tests/database.test.mjs`: account isolation, offline saving, guest import, Google flow and actual PostgreSQL permission tests.

## Curriculum scope

Transcribed from the five supplied DLSU AY2022–2023 ID122 checklists. Only technical courses are modeled; GE, PE, NSTP and OJT are excluded from the app’s technical progress denominator. CIVINCO is a common integration gate outside the course denominator. Shared Urban Engineering (CESPECS) remains shared because it appears in all five checklists. Specialist lecture courses are required mastery nodes when selected; laboratories are academic requirements only. This scope can be changed in `MASTERY_SCOPE` and course `requiredMastery` fields.

H prerequisites require academic completion, S prerequisites require an activated or completed record, and lecture co-requisites activate together after checking both courses’ prerequisites. Lab co-requisites are directional: the lecture must already be active or completed in the current or an earlier recorded term; activating the lecture never activates its lab. My journal sets the self-reported year and current term. New academic records store `takenInTerm`; legacy records without term data retain their status and eligibility. This skeleton uses self-reported app records; it does not assert enrollment or university verification. Quizzes have service boundaries and historical record storage but no user-facing assessment content yet. Hardmode uses configurable common domain groupings, with review content deferred. A recorded CIVINCO pass remains valid through a transfer; active-path eligibility is recalculated separately.

The academic journey meter uses shared requirements plus the confirmed specialization; inspecting another branch never changes its scope. Reset progress is available on the map and in My journal, with explicit confirmation before clearing this app’s saved records and returning to Year 1.

Guest progress resides in the current browser. With Supabase configured, Google sign-in loads a private account journey and saves changes across devices. Account caches are separated from guest saves, first-time guest import requires a choice, and revision checks detect conflicting device saves. Export preserves the full progression record. See [DEPLOYMENT.md](DEPLOYMENT.md) for Cloudflare Pages, database migration, public configuration, and Google OAuth setup. The galaxy is a local generated bitmap; constellation geometry uses attributed d3-celestial data (see `src/data/README.md`). Hanyi WenHei 85W is the bundled primary UI typeface, supplied by the project owner in `hywenhei.zip`. `font-face.css` and the build load `src/assets/fonts/HYWenHei-85W.ttf` (see its README). Manrope/Arial is the loading fallback. Cinzel supplies Roman numerals. `interface.css` defines the final chart annotation and instrument styling.

## Motion

`sky-motion.mjs` and `motion.css` add drifting background stars, bounded mouse parallax, a gently tilting course chart, selected-path light flow and completion sparks. Decoration never changes camera coordinates, hit targets, or progression. Touch devices use fewer background stars without pointer tilt. Motion pauses while the map is hidden or a dialog is open and respects reduced-motion preferences. Completed nodes use a small inner-star glow instead of a wide blurred outline.

## Companions and mobile atlas

The specialization selector starts collapsed. Selecting a branch reveals it on the shared sky and closes the dropdown. Explore All opens it in read-only mode. The near-black atlas uses quiet warm controls while retaining the constellation colors and supplied font.

My companion opens a wardrobe with four original illustrated avatars and milestone frames at 0, 1, 8 and 24 completed curriculum courses. Historical completion counts keep earned cosmetics available through specialization transfers. Cosmetic choices travel with the account progression JSON and are separate from academic/mastery requirements; older saves receive default cosmetics. No database migration is needed for these optional JSON fields.

Touch controls support one-finger pan, midpoint-anchored two-finger zoom/pan, and one-finger continuation after a pinch. Gestures suppress accidental course clicks. Mobile controls are at least 44px, course chapters scroll internally, and profile/login actions remain available in the compact header.

Account sign-in offers Google and username/password accounts without asking for student email. Enable the username signup hook and Supabase password-provider settings described in `DEPLOYMENT.md` before using username registration. Supabase manages passwords and the same private progress table for either login method. Username accounts recover without email using single-use codes after the private server setup in [RECOVERY_SETUP.md](RECOVERY_SETUP.md). Pending cloud saves require a choice before signing out, and reconnecting automatically retries offline saves. Returning to a visible page refreshes an unchanged account journey from the cloud. Public production settings live in `config/public-production.json`; the build validates them and applies them only to Cloudflare's production `main` branch unless environment variables explicitly override them. `/runtime-config.mjs` shows the actual browser configuration.

The interface uses black surfaces and neutral controls around the colored constellations. The taller map has an expanded view, with Escape to return and camera centering preserved across resizing. Inactive stars remain faint; activated stars have a restrained glow and completed stars have the strongest glow in their constellation color. The star facets glow; the circular aura is removed and the elevation base stays subdued. Constellation trails reflect activation and completion at separate brightness levels. Brighter text, gentle starfield shimmer, focused hover movement and course-panel transitions preserve the black theme and respect reduced motion. Password inputs include accessible Show/Hide controls. Recovery codes are separate from progression data.
